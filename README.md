# 昭和医科大学医学部陸上部 公式サイト

昭和医科大学医学部陸上部の活動情報を掲載する、スマートフォン・PC対応の静的ウェブサイトです。練習予定や大会情報、新入生向けのお知らせを確認できるほか、英語ページ、部員向けダッシュボード、ミニゲームなどを提供しています。

## サイトの機能

### トップページ

`index.html` はサイトのポータルです。ページ上部には登録済みの大会のうち次に開催される大会名と開催日までの日数を表示します。練習予定は日付、曜日、場所、最寄り駅、開始時刻とあわせて表示され、予定に緯度・経度と時刻がある場合は天気予報と気温も確認できます。

予定データに登録がない日については、月曜・水曜の駒場練習、金曜の夢の島陸上競技場練習を既定の予定として補完します。練習予定の天気情報はOpen-Meteoから取得します。トップページからは、練習メニュー、大会スケジュール、部員専用ページ、記録登録フォーム、新しいお知らせ、Instagram、LINE公式アカウントへ移動できます。ヘッダーの言語切替から英語ページも開けます。

### 練習メニュー

`menu/` ではGoogle Apps Script（GAS）のウェブアプリからメニュー情報を取得し、ブロックごとのカードとして表示します。取得したデータの末尾から直近3件を掲載し、メニューの内容、ブロック名、曜日などの情報を確認できます。データが空の場合や通信に失敗した場合は、その状態をページ上に表示します。

### 大会スケジュール

`schedule/` は大会予定を時系列のタイムラインで表示します。大会名、開催日、会場、参加予定人数、補足を確認できます。開催日で並べ替えてから表示するため、予定を順番に把握できます。現在のスケジュールはページ内に記載された年度の情報です。

### お知らせ・秋合宿

`autumn_camp/` には秋合宿の3日間の予定と、2日目午前に実施する1年生向けの富士吉田新歓の案内を掲載しています。晴天時・雨天時の予定や行動内容を確認でき、集合場所、タイムスケジュール、持ち物などを案内する縦長ポスターもページ内に表示します。ポスターは画面幅に応じて縮小されます。

### 部員専用ダッシュボード

`members.html` には、部員向けの練習最適化ダッシュボードを埋め込んでいます。案内上は学籍番号または付与されたパスワードでログインし、個人の記録推移や推奨練習メニューを確認するページです。ダッシュボードの閲覧には外部のLooker Studioと、そのデータへのアクセス権が必要です。このページにはトップページへ戻るリンクがあります。

### 英語ページ

`english/` は留学生・海外出身の学生向けの英語ポータルです。部の紹介、参加案内、InstagramとLINEへのリンクに加え、最新の練習予定を英語で表示します。練習場所、最寄り駅、開始時刻、天気情報も掲載します。日本語トップページへの切替リンクがあります。

### ミニゲーム

- `minigame/raiden-x/` は、敵を撃ちながら進む縦スクロールシューティングゲームです。スコア、残機、ボムを表示し、武器やアイテムを使ってプレイできます。PCでは矢印キーまたはWASDで移動し、SpaceまたはZで射撃、BまたはXでボムを使用します。スマートフォンでは画面上の方向キーと射撃・ボムボタンを使えます。ゲームオーバー後はRキーまたは画面タップで再開します。
- `minigame/chariso/` は自転車で地形を進むアクションゲームです。地面の穴や坂をジャンプで越え、進んだ距離を記録します。Space、上矢印、マウスクリック、または画面タップでジャンプでき、空中では最大2回までジャンプできます。ゲームオーバー画面をクリックまたはタップすると再スタートします。

## ファイル構成

| パス | 内容 |
| --- | --- |
| `index.html` | 日本語トップページ（`build.py` が生成する公開用ページ） |
| `template.html` | トップページのテンプレート。練習予定の挿入位置を含みます |
| `build.py` | GASから練習予定を取得し、テンプレートから `index.html` を生成するスクリプト |
| `menu/index.html` | 最新の練習メニューを表示するページ |
| `schedule/index.html` | 大会スケジュールのタイムライン |
| `autumn_camp/index.html` | 秋合宿・秋新歓のお知らせ |
| `autumn_camp/poster_9_16.html` | お知らせページに埋め込む縦長ポスター |
| `members.html` | 部員向けダッシュボード |
| `english/index.html` | 英語ポータル |
| `minigame/` | ブラウザー上で遊べるミニゲーム |
| `old/` | 旧ページや過去の資料 |
| `.github/workflows/build.yml` | 定期実行と手動実行に対応したビルド用GitHub Actionsワークフロー |
| `sitemap.xml` | 検索エンジン向けサイトマップ |

## ビルドと公開

トップページを生成するには、リポジトリのルートでPython 3を使って次を実行します。

```bash
python build.py
```

スクリプトはGASのウェブアプリから練習予定を取得し、`template.html` 内の `<!-- INJECT_PRACTICE_HERE -->` を予定表示用HTMLに置き換えて `index.html` を書き出します。予定を取得できなかった場合は、予定未登録の表示でページを生成します。

GitHub Actionsの `Auto Build & Deploy` ワークフローは毎日（日本時間0時）に実行されるほか、GitHub Actionsから手動実行できます。実行時に `build.py` を動かし、生成されたファイルに差分がある場合はコミットしてプッシュします。

サイトをローカルで確認する場合は、生成済みのHTMLをブラウザーで開くか、リポジトリのルートで簡易HTTPサーバーを起動します。

```bash
python -m http.server 8000
```

ブラウザーで `http://localhost:8000/` を開いてください。練習予定・メニュー・天気・ダッシュボードなどの外部データを使う機能は、ネットワーク接続や各外部サービスの公開設定に依存します。
